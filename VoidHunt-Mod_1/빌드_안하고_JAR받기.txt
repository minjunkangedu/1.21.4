║    GitHub이 대신 빌드해주고, 완성된 .jar만 내려받으면 됨.     ║

준비물: GitHub 계정(무료) 하나. 프로그램 설치 X.

────────────────────────────────────
1) 저장소 만들기
   - github.com 로그인 → 오른쪽 위 "+" → New repository
   - 이름 아무거나(예: voidhunt) → Create repository

2) 이 프로젝트 파일 올리기
   - 방금 받은 zip을 컴퓨터에서 "압축 풀기"
   - 저장소 페이지 → "uploading an existing file" 링크 클릭
   - 압축 푼 폴더 "안의 내용물 전부"를 드래그해서 업로드
     (build.gradle, settings.gradle, gradle.properties, src 폴더,
      .github 폴더 등이 최상위에 오도록. VoidHunt-Mod 폴더 자체가 아니라
      그 안의 파일들을 올리는 것!)
   - 아래 "Commit changes" 클릭

3) 자동 빌드 기다리기
   - 올리면 자동으로 빌드가 돌아감(.github/workflows 때문에)
   - 저장소 상단 "Actions" 탭 → 실행 중인 작업 클릭
   - 초록 체크(성공) 뜰 때까지 1~3분 대기
     · 초록색이면 성공. 빨간 X면 5번 참고.

4) 완성된 .jar 내려받기
   - 성공한 작업(Actions의 그 실행) 페이지 맨 아래
     "Artifacts" → "VoidHunt-mod-jar" 클릭해서 다운로드
   - 압축 안에 voidhunt-1.0.0.jar 가 들어있음 ← 이게 진짜 모드!

────────────────────────────────────
5) 설치 (★ 중요: 서버가 아니라 "내 게임"에)
   - 내 마크에 Fabric 설치돼 있어야 함 (fabricmc.net → 1.21.4)
   - 아래 두 개를 "내" .minecraft/mods 폴더에 같이 넣기:
       · voidhunt-1.0.0.jar   (방금 받은 것)
       · Fabric API           (modrinth/curseforge에서 1.21.4용)
   - 게임 실행

6) 사용
   - /give @s voidhunt:void_shades  → 우클릭으로 머리에 착용
   - H 키로 헌트모드 on/off
   - 착용하면 가장 가까운 적 자동 락온 + 사거리 안이면 자동 공격

────────────────────────────────────
※ 왜 서버에 넣으면 안 되나?
  HUD·자동타겟·자동공격은 "각 플레이어 클라이언트"에서 도는 기능이라
  서버 mods에 넣어도 화면에 아무것도 안 나와요. 내 게임에 넣어야 합니다.
  (친구들도 보게 하려면 각자 클라에 같은 jar를 넣어야 함)

※ 빌드가 빨간 X로 실패하면?
  Actions의 실패한 작업 → 빨간 단계 클릭 → 에러 로그가 나옵니다.
  그 로그(특히 'error:' 줄)를 저한테 그대로 복사해서 주세요.
  버전/이름만 맞추면 바로 통과됩니다.
